# BRS

Проект автоматизирует сбор БРС от преподавателей. Принимает ответы из Яндекс Формы, генерирует Word-документы и управляет уведомлениями по почте

---

## Сам процесс:

1. Преподаватель заполняет форму яндекс с данными БРС (указывая свои фио, корпоративную почту, название предмета, для которого заполняет БРС)
2. Яндекс отправляет POST-запрос на сервер
3. Сервер сохраняет JSON в `captures/` и генерирует `.docx` в `output/`
4. Преподаватель получает подтверждение на email (о том, что его форма была получена)
5. Демон уведомлений по расписанию шлет напоминания не сдавшим и ежедневные отчеты заведующему кафедрой

---

## Структура проекта

```
brs-project/
├── main.py # FastAPI сервер, принимает вебхуки от Яндекс Форм
├── brs_generator.py # генерация word-документа из JSON
├── notify.py # почтовые сообшения (отчеты для зав. кафедрой, напоминания о том, что необходимо заполнить форму)
├── teachers.txt # общий список преподавателей
├── .env # переменные окружения (хранятся чувствительные данные)
├── data/ # шаблон .docx
├── captures/ # сохраненные JSON, полученные от формы
└── output/ # сгенерированные .docx файлы
```

## Что требуется сделать:

### 1. Клонировать репозиторий

```bash
git clone https://github.com/vgntmh0803gns-dev/brs
cd brs
```

### 2. Виртуальное окружение и зависимости

```bash
python -m venv .venv

# Windows CMD:
.venv\Scripts\activate.bat

# Windows PowerShell:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.venv\Scripts\Activate.ps1

# Mac/Linux:
source .venv/bin/activate

pip install -r requirements.txt
pip install python-dotenv
```

### 3. Настроить `.env`

Скопировать шаблон и заполнить:

```bash
cp env.example .env
```

```env
# яндекс-почта кафедры (с этого адреса уходят все письма, дополнительно надо настроить все для успешной отправки - см. далее)
YANDEX_EMAIL=kafedra@yandex.ru

# пароль ПРИЛОЖЕНИЯ (не обычный пароль от почты!)
YANDEX_PASSWORD=xxxx-xxxx-xxxx-xxxx

# ссылка на Яндекс Форму, которая будет вставляться в письма-напоминания для преподавателей
BRS_FORM_LINK=https://forms.yandex.ru/cloud/...

# почта зав. кафедрой (сюда приходят ежедневные отчеты с файлами, заполненными за день)
HEAD_EMAIL=head@example.ru

# время отправки ежедневного отчета (формат ЧЧ:ММ)
REPORT_TIME=18:00

# дни месяца для отправки напоминаний не сдавшим (через запятую)
REMIND_DAY=1,15,25

# за сколько дней считать преподавателя "сдавшим" БРС
# система считает преподавателя "сдавшим", если он заполнил форму в течение последних PERIOD_DAYS дней
PERIOD_DAYS=30
```

#### Настройка почты Яндекса

Чтобы отправка писем работала, нужно сделать два шага:

**Шаг 1: создать пароль приложения:**
[ya.ru](https://ya.ru) → Управление аккаунтом → Безопасность → Пароли приложений → Почта → придумать название → сохранить пароль в `YANDEX_PASSWORD`

**Шаг 2: разрешить доступ почтовых программ:**
[Яндекс Почта](https://mail.yandex.ru) → Настройки → Почтовые программы → включить следующие параметры:

- С сервера imap.yandex.ru по протоколу IMAP
- Пароли приложений и OAuth-токены

### 4. Создать `teachers.txt`

Один преподаватель на строку, формат: `ФИО;Предмет;email`

```
Иванов Иван Иванович;Математический анализ;ivanov@example.ru
Петрова Анна Сергеевна;Физика;petrova@yandex.ru
```

Комментарии (`#`) и пустые строки игнорируются.
Если у преподавателя несколько предметов - добавить несколько строк.

### 5. Запустить сервер

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Проверить: открыть http://localhost:8000 — должен вернуть `{"status": "ok"}`.

### 6. Открыть туннель (Cloudflare)

В отдельном окне терминала:

```bash
# Скачать cloudflared.exe с https://github.com/cloudflare/cloudflared/releases/latest
# Положить в папку проекта, затем:

cloudflared.exe tunnel --protocol http2 --url http://localhost:8000
```

Туннель выдаст адрес вида `https://xxxx-xxxx.trycloudflare.com`.

> **Внимание:** адрес меняется при каждом перезапуске. Для постоянной работы
> рекомендуется развернуть сервер на VPS с фиксированным адресом.

### 7. Настроить интеграцию в Яндекс Форме

Конструктор формы → Интеграции → HTTP-запрос:

- **URL:** `https://<твой-адрес>.trycloudflare.com/webhook`
- **Метод:** POST
- **Тело:** Ответы на все вопросы в виде JSON
- **Заголовок:** `Content-Type: application/json`

## Уведомления (`notify.py`)

### Ручной запуск

```bash
# Показать кто не сдал (без отправки писем):
python notify.py --list

# Отправить напоминания не сдавшим:
python notify.py --remind

# Отправить зав. кафедрой отчет с файлами за последние сутки:
python notify.py --report

# Оба действия сразу:
python notify.py --remind --report

# Указать произвольный период анализа (--period - это способ переопределить PERIOD_DAYS из командной строки, не меняя .env; значение в днях)
python notify.py --list --period 60
```

### Автоматический режим (демон)

```bash
python notify.py --daemon
```

Крутится фоном и по расписанию из `.env`:
- каждый день в `REPORT_TIME` отправляет отчет зав. кафедрой
- в указанные дни месяца (`REMIND_DAY`) - отправляет напоминания не сдавшим

Если за сутки никто не заполнил форму, то отчет все равно отправляется, но без вложений

---

## Важные детали интеграции Яндекс Форм

- Успешный ответ сервера — коды **200 / 201 / 202**. Иначе Яндекс повторяет запрос до 7 раз за 30 минут.
- Заголовок `x-delivery-id` одинаковый у повторов одного запроса (для дедупликации).
- ID вопросов формы жёстко прописаны в `brs_generator.py` и `notify.py`. При использовании другой формы нужно обновить ID, посмотрев их в `captures/*.json` после тестовой отправки.
