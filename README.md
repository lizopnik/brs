# BRS Docenko — интеграция с Яндекс Формами

Проект из двух этапов:
1. **Шаг 1 (сейчас):** поднять сервер-перехватчик, настроить интеграцию с
   Яндекс Формой и узнать реальный формат приходящего JSON.
2. **Шаг 2 (позже):** на основе этого JSON генерировать Word-документ.

## Шаг 1. Узнаём формат JSON

### 1. Установка зависимостей

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Запуск сервера

```powershell
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Проверь, что работает: открой http://localhost:8000 — должен прийти JSON
`{"status": "ok", ...}`.

### 3. Туннель в интернет (Cloudflare Tunnel)

Яндекс Формы умеют слать запросы **только по IPv6**. Cloudflare Tunnel
решает это: запрос идёт на dual-stack edge Cloudflare (доступен по IPv6),
а `cloudflared` сам соединяется наружу с твоего компа — белый IP и проброс
портов не нужны.

Установить `cloudflared` (один раз):
```powershell
winget install --id Cloudflare.cloudflared
```

Поднять быстрый туннель (в отдельном окне, сервер должен быть запущен):
```powershell
cloudflared tunnel --url http://localhost:8000
```

`cloudflared` выдаст публичный адрес вида
`https://random-words-1234.trycloudflare.com`. Это и есть наш URL.

> Альтернатива, если есть VPS с IPv6 — развернуть сервер прямо на нём,
> туннель тогда не нужен.

### 4. Настройка интеграции в Яндекс Форме

В конструкторе формы → **Интеграции** → добавить **HTTP-запрос**:

- **URL:** `https://<твой-адрес>.trycloudflare.com/webhook`
- **Метод:** `POST`
- **Заголовок:** `Content-Type: application/json`
- **Тело запроса (JSON):** подставь сюда переменные всех вопросов формы,
  например:
  ```json
  {
    "answers": {
      "fio": "{Вопрос: ФИО}",
      "email": "{Вопрос: Email}",
      "comment": "{Вопрос: Комментарий}"
    }
  }
  ```
  (точный синтаксис переменных Яндекс подставит сам из списка вопросов)

### 5. Тестовая отправка

Заполни и отправь форму. В консоли сервера появится тело запроса, а в папке
`captures/` — файл `request_*.json` со всем, что пришло (заголовки + тело).

Покажи мне содержимое этого файла — зафиксируем схему и перейдём к Word.

## Важные детали интеграции (из документации Яндекса)

- Успешный ответ — коды **200 / 201 / 202**. Иначе запрос повторяется до 7
  раз в течение 30 минут.
- Заголовок `x-delivery-id` — одинаковый у повторов одного запроса
  (для дедупликации).
- Структуру тела JSON ты задаёшь **сам** в настройках интеграции —
  Яндекс лишь подставляет в неё ответы пользователя.
